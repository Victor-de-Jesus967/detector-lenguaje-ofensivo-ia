# Guion para la Actividad 4.2 (duración sugerida: 8 minutos)

1. **Portada (30 s):** TecNM Virtual, materia, unidad, nombre, fecha.
2. **Problema y alcance (1 min):** clasificación de lenguaje ofensivo en inglés; riesgo de moderación automática.
3. **Datos y preparación (1 min):** TweetEval, dos clases y particiones oficiales; limpieza mínima y TF-IDF.
4. **Pipeline (1 min):** entrenamiento, 3-fold cross-validation, búsqueda de hiperparámetros, validación y prueba.
5. **Resultados (1.5 min):** mostrar `results/metricas.json`, F1 macro, F1 ofensivo, matriz de confusión. Usar solo métricas efectivamente obtenidas.
6. **Despliegue (2 min):** abrir Streamlit, analizar mensajes en inglés y observar clasificación y latencia. Usar ejemplos redactados por ti.
7. **Análisis crítico y ética (1 min):** errores FP/FN, sesgo lingüístico, revisión humana, ausencia de validación para español; proponer expansión y pruebas de carga.
8. **Fuentes (pantalla final):** citar TweetEval (Barbieri et al., 2020), documentación scikit-learn y Streamlit.

No afirmar que el sistema está listo para producción, ni que detecta intenciones o contextos con fiabilidad garantizada.
